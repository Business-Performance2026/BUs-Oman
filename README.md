# رحلاتك 🚌 — منصة حجوزات النقل (نسخة تعمل بـ Firebase)

تطبيق ويب حقيقي متصل بـ **Firebase Auth + Firestore**. ثلاث صفحات:

| الصفحة | المسار | الوظيفة |
|---|---|---|
| الرئيسية | `index.html` | اختيار الدخول: شركات / إدارة |
| العميل | `customer.html?c=رابط-الشركة` | يفتح فقط بالرابط أو الباركود — عرض الرحلات والحجز والتذكرة |
| الشركة | `company.html` | تسجيل شركة، لوحة تحكم، رحلات، موظفون، رابط وباركود |
| الأدمن | `admin.html` | تفعيل/إيقاف الشركات، إحصائيات، الروابط والباركودات |

## 🚀 خطوات التشغيل (مرة واحدة)

### 1) تفعيل Firestore
- في [console.firebase.google.com](https://console.firebase.google.com) → مشروع **bus-oman**
- من القائمة: **Build → Firestore Database → Create database**
- اختر **Start in production mode** وأقرب منطقة

### 2) نشر قواعد الأمان
من جهازك داخل مجلد المشروع:
```bash
firebase deploy --only firestore:rules
```
(أو انسخ محتوى `firestore.rules` والصقه في تبويب **Rules** داخل Firestore ثم اضغط Publish)

### 3) إنشاء حساب الأدمن (أنت)
1. في Firebase Console: **Authentication → Users → Add user**
   - أدخل إيميلك وكلمة مرور قوية
2. انسخ **UID** الخاص بالمستخدم الذي أنشأته
3. في **Firestore → Start collection**:
   - Collection ID: `users`
   - Document ID: الصق الـ UID
   - حقل واحد: `role` (نوعه string) القيمة: `admin`
4. الآن تقدر تدخل من `admin.html` بهذا الإيميل

### 4) الرفع على GitHub والنشر
```bash
git add -A
git commit -m "نسخة تعمل بـ Firebase"
git push
firebase deploy --only hosting
```

## ✅ سير العمل

1. صاحب الشركة يفتح `company.html` → **سجّل شركتك الآن** → يصله **إيميل تحقق** تلقائيًا
2. حسابه يصبح «قيد المراجعة» ولا يستطيع الدخول للوحة
3. **أنت** تدخل `admin.html` → تشوف الطلب في «طلبات التفعيل» → تضغط ✔️
4. الشركة تُفعّل → يشتغل رابطها `customer.html?c=اسم-الشركة` وباركودها
5. الشركة تضيف رحلات وموظفين → العميل يفتح الرابط ويحجز → الحجز يظهر للشركة وللأدمن

## ملاحظات

- الموظفون الذين تضيفهم الشركة يحصلون على حساب دخول حقيقي (إيميل + كلمة مرور)
- العميل لا يحتاج حسابًا — يحجز مباشرة ويسترجع تذاكره برقم الواتساب
- لإيقاف شركة: من لوحة الأدمن ⛔ — يتعطل رابطها فورًا
